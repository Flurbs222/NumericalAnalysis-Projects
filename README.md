# Numerical Analysis Projects (1-5)
Larger-form Python projects employing Numerical Analysis:
1. Finding roots of functions using Bisection, Newton, and Secant methods
2. Interpolating functions using Lagrange, Divided Difference, Cubic Spline, and Vectorization
3. Solving systems of linear equations using Gaussian Elimination, Inverse Matrix, Jacobi, and Gauss-Seidel methods
4. Compressing data using Fourier vs Discrete Fourier Approximation methods
5. Compressing images using Singular Value Decomposition (SVD) and QR methods
